{%- comment -%} Photo carousel for /symposium/. Photographs are read straight from `images/decennial/` at build time via site.static_files — drop a file in that folder and push, and it appears. They are shown in filename order, so a numeric prefix (01-…, 02-…) fixes the sequence. If the folder holds no images, this include renders nothing. Captions are optional and live in `_data/decennial.yml` as `: "caption"`. A photograph with no caption entry simply has no caption, and falls back to a generic alt text. No external library, no autoplay; native swipe via CSS scroll-snap, plus buttons, dots and arrow keys. Honours prefers-reduced-motion. {%- endcomment -%} {%- assign symp_photo_ext = ".jpg.jpeg.png.webp.avif" -%} {%- assign symp_photo_files = site.static_files | where_exp: "f", "f.path contains '/images/decennial/'" | sort: "name" -%} {%- assign symp_photo_list = "" -%} {%- for f in symp_photo_files -%} {%- assign e = f.extname | downcase -%} {%- if symp_photo_ext contains e -%} {%- assign symp_photo_list = symp_photo_list | append: f.path | append: "||" -%} {%- endif -%} {%- endfor -%} {%- assign symp_photos = symp_photo_list | split: "||" -%} {%- if symp_photos.size > 0 -%}
